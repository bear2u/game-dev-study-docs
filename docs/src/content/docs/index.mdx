## GitHub Pages 배포 방법

이 문서는 Cloudflare의 **Nimbus (Astro)** 기반 정적 사이트이며, `.github/workflows/deploy.yml`이 이미 포함되어 있습니다.

<Steps>
  <Step title="GitHub 저장소 생성 및 푸시">
    이 워크스페이스를 GitHub 저장소의 `main` 또는 `master` 브랜치에 푸시합니다.
  </Step>
  <Step title="GitHub Pages 설정">
    GitHub 저장소의 **Settings → Pages → Source**에서 **GitHub Actions**를 선택합니다.
  </Step>
  <Step title="자동 빌드 및 배포 확인">
    푸시 시 자동으로 `docs/`를 빌드하여 `https://<username>.github.io/<repo-name>/` 주소로 배포됩니다.
  </Step>
</Steps>
