## 4. 실전 공부 체크리스트

<Aside type="note" title="매 프로젝트마다 점검할 5가지">
  1. **고객 기준:** 이 결정의 이유를 "유저(고객)"에게 떳떳하게 설명할 수 있는가? (03강)
  2. **단일 이상안:** 플랜 B 뒤에 숨지 않고, 내가 믿는 최선의 1안을 제시했는가? (11강)
  3. **내압 유지:** 아직 구체화되지 않은 아이디어를 SNS나 잡담으로 미리 소모하고 있지 않은가? (14강)
  4. **콘셉트 사수:** 일정과 피로에 밀려 작품의 핵심 매력을 타협하려 하고 있지 않은가? (07·17강)
  5. **즉시 실행:** 완벽한 준비를 기다리느라 손이 멈춰 있지 않은가? (09강)
</Aside>
